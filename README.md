PoseNova AI — Managed C2C Fashion Styling & AI Pose Platform
1. Executive Summary
PoseNova AI is an advanced fashion-tech ecosystem integrating Generative Artificial Intelligence (Google Gemini API, ML Kit Pose Detection) with a robust milestone-based escrow payment architecture. The project addresses financial transparency and accountability challenges between everyday users and professional stylists, while providing real-time AI-assisted fashion posing and tracking capabilities.

2. Core Business Workflows
Discovery & Affiliate Shopping: Explore curated fashion lookbooks and interact with embedded product tags (PRODUCT_TAG) linked directly to affiliate e-commerce channels.

AI Pose Camera: Extract 33 skeletal keypoints in real-time (30 FPS), compute pose matching accuracy (Pose Match %), and capture photos automatically upon threshold validation.

Milestone Escrow & Tracking (Featured Workspace): Manage styling progression across 3 structured stages (30% - 30% - 40%), enforce revision constraints (RevisionCount < 2), and execute automated escrow payouts via SePay Webhooks.

Stylist Wallet & Ledger: Handle available balances (WALLET.Balance) and reconcile multi-party transaction histories (PAYMENT_TRANSACTION).

3. Technology Stack
Frontend: Flutter / Dart (Cross-platform Mobile UI)

Backend: Node.js, Express.js, Supabase (PostgreSQL Database & Object Storage)

AI & Computer Vision: Google Gemini API (Structured Output Parsing), Google ML Kit Pose Detection

UI/UX Design System: Neo-Brutalist Cyber-Streetwear (Technical grid-paper background, crisp 1px/2px black borders, hard offset shadows, high-contrast OKLCH color tokens).
